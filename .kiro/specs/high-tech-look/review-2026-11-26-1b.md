### 1.2/1.7 in site-look-1b.test.js (line 108) -- TEST BUG

`lastRule('.book::before')` returns the last `.book::before` match in the whole file. **Product code is correct** -- the main `.book::before` at line 2870 has `content: ""`, the spine gradient, etc. The fix is in the test: `lastRule` needs to either skip rules inside media queries or the test should directly search the CSS for the main rule.

## 4. Contrast failure -- PRODUCT CODE BUG

**The lit tab fails WCAG AA contrast.**

`.book-tab.is-on` uses `color: var(--color-button-text)` (#FFFEF9, near-white) on `background: var(--color-gold)`:

| Mode  | Background | Foreground | Ratio | Needed (12px bold) | Pass? |
|-------|-----------|------------|-------|---------------------|-------|
| Dark  | #FFB547   | #FFFEF9    | 1.74:1 | 4.5:1              | FAIL  |
| Light | #B8893B   | #FFFEF9    | 3.11:1 | 4.5:1              | FAIL  |

The tab letter is 12px 700-weight. Even if treated as large text (14px bold), the 3:1 threshold still fails in dark mode (1.74:1).

**Fix needed:** Use a dark text color on the gold background -- for example, `--color-ink` (#0F1B33 dark, #0F1B33 light) would give ratios well above 4.5:1 on both gold values.
