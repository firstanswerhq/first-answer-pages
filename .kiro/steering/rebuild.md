# Rebuild in progress (grader)

- The terminal on this laptop returns no output (exit code -1). Do not run shell commands, tests or installs here; they will hang waiting for approval and tell you nothing.
- Tests are run in the cloud after each task, and the results come back to you in chat. Write the code and the tests, then stop and say which task is done.
- Build only what the current task says, following the requirements and design in this spec and the other steering files.
- The existing tests in `test/` are the acceptance bar. Read the tests for a module before writing it, so names, exports and messages match exactly.
